# KEYROADS CRM — Scope Approval Portal

Static responsive website including a detailed per-feature review checklist, exclusions, maintenance/ownership terms, deposit details, and a drawn e-signature.

## Preview
Open `index.html` in a modern browser or host these files over HTTPS.

## Publish with GitHub Pages
1. Create a **dedicated repository** and add `index.html` and `keyroads-logo.png` to its root.
2. Repository **Settings → Pages → Build and deployment → Deploy from a branch**; select `main` and `/ (root)`.
3. Share the resulting GitHub Pages link. **GitHub Pages is publicly viewable by default**, even if you use a private repo under some plan configurations. This page includes business terms and bank transfer instructions, so only publish if you're comfortable making those visible on the public internet.

## Important: approval-record limitations
This is a client-side preview, NOT an audit-backed online-signature service. Feature selections, signatures and notes are not automatically saved to a backend or sent to the developer. The client must download their signed HTML copy and send it back for countersignature. For formal remote approval, integrate an e-signature provider or protected backend that records the precise agreement version, identity verification, timestamp, and immutable signed PDF; configure emails to both parties. Avoid storing signing submissions in public GitHub issues or commits.
